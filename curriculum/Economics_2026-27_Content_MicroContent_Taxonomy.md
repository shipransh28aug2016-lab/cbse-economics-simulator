# 2. Common Curriculum Architecture

## 2.1 Core Learning Intent

The syllabus emphasizes:

1. Basic economic concepts and economic reasoning.
2. Application of economics to everyday life.
3. Understanding India's economic realities.
4. Basic statistical tools for analysing economic information.
5. Logical argumentation and interpretation.
6. Project-based exploration of real-world economic issues.
7. Use of ICT to facilitate learning.
8. Development of analytical, evaluative and creative thinking.

## 2.2 Common Content Layers

Every syllabus unit can be treated as a hierarchy:

**Part → Unit → Topic → Sub-topic → Micro-concept → Skill → Application → Assessment**
