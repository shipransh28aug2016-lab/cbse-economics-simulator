# Economic-correctness audit — November 2026 (the 34 non-Graph-Lab sims)

**Method.** For each sim: read its `compute()` / `calculate()` / content, state the economic
rule it claims in one precise sentence, then test that sentence numerically against the
real model across each control's full domain. A dead-zone scanner flagged every control
that moves while every output stays frozen. A finding counts only when the model
contradicts the CBSE/NCERT (Sandeep Garg) rule or its own on-screen text. Each finding has
a regression test in `tools/test-curriculum.js` (`testAuditRegressions`). On the pre-fix
code those tests fail **96 assertions covering all 14 findings**; on the fixed code they
all pass.

This follows the Graph Lab pass, which found the producer-equilibrium and cost-minimum
bugs (`docs/economics/models/producer-equilibrium.md`).

## Checked and found correct

Central tendency (mean, odd/even median, multiple modes), data organisation (grouped
median L + ((N/2 − cf)/f)·h), index numbers (simple aggregative), presentation shares,
propensity (fitted MPC, honestly labelled), money multiplier (1/LRR), indifference curves
(MRS = Px/Py with Cobb-Douglas demands), price controls, correlation, national-income
methods, poverty/Lorenz (Gini = (k−1)/(k+1), exact for L = p^k), the neighbours data
(marked illustrative, broadly accurate for ~2023), timelines (Planning Commission 1950,
1991 BoP crisis, demonetisation 2016, GST 2017) and every classification answer key
(positive/normative, stock/flow, final/intermediate, consumption/capital goods).

The dead-zone scanner also flagged three cases that are **correct economics** and were left
alone: poverty headcount under perfect equality (everyone has the same income, so it is 0%
or 100%), demand at a controlled price above the choke price (zero at any demand level),
and output when price is below the minimum of MC (shutdown, whatever MC's slope).
